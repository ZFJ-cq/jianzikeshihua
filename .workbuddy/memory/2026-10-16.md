## 剪纸坊 · 剪纸可视化模拟 App（从零构建）
- 交付物：`/Users/macbook/前端项目/剪纸可视化裁剪/index.html`（单文件，~969 行，纯前端零依赖）+ `README.md`。
- 核心思路：在爆红「中国留学生剪纸模拟」的「折叠→画线→展开」基础上做系统化创新。
- 关键实现：
  - 折叠对称用几何对称群：以圆心为基准对折叠域笔画做 n 次旋转；开启镜像时**先在扇区自身平分线(-π/2)做镜像、再随扇区旋转**，使相邻扇区在折痕处互为镜像 → 标准 Dₙ 对称（修正了一个 bug：原先绕 phi_k=-π/2+kθ 反射会把扇区搬移到 2kθ，与旋转副本重合，镜像开关实际无效）。
  - 镂空渲染用 Canvas `globalCompositeOperation='destination-out'`，孔洞透出画布 CSS 背景（窗花质感）。
  - 五种折法：方形对折(rect 右半镜像)、三角/四/六/八折(sector，n=3/4/6/8)。
  - 实时预览 + 扇面展开动画（逐扇区插值旋转角）。
  - 作品集 localStorage 持久化 + 缩略图 + 线稿/辅助线切换视图。
  - 练习模式：幽灵参考线 + IoU 掩膜重合度评分。
- 校验：node --check 通过；对称数学单测通过（扇区内镜像左右对称、副本均在圆内、六折 12 副本）；DOM id 引用全部存在。
- 本地预览：`python3 -m http.server 8137`（已起，HTTP 200）。
