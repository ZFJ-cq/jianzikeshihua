# 剪纸坊 · 剪纸可视化模拟 App

在曾经网络爆红的「中国留学生剪纸模拟」思路（折叠 → 画线 → 展开）之上做的系统化创新实现。
纯前端、单文件、零依赖，**直接双击 `index.html` 即可运行**，也可一键部署到 GitHub Pages。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 1. 可视化模拟 | 折叠台上以几何模型展示折纸，裁剪后右侧**实时**渲染整幅展开效果，并提供「扇面展开」动画还原折→剪→展的物理过程。 |
| 2. 折叠选择 | 内置 **方形对折 / 三角三折 / 四角四折 / 六角六折 / 八角八折** 五种折法，并用对称群精确还原每种折法的旋转 + 镜像关系；可一键切换「镜像对称」得到 Dₙ 或 Cₙ 对称。 |
| 3. 触控裁剪 | 操作台基于 Pointer 事件统一支持手指与鼠标，可在折纸上绘制裁剪路径；提供**描边 / 填充**两种笔法、笔触粗细、撤销/重做/清空。 |
| 4. 效果查看 | 裁剪结束即时预览成品；可切换「线稿」（裁剪路径蓝图）与「辅助线」（折痕与对称轴）视图；支持导出 PNG。 |
| 5. 作品集 | 完成的作品自动存入浏览器（localStorage），缩略图墙展示；点击查看成品，并切换线稿/辅助线，可删除或在创作台打开。 |
| 6. 练习模式 | 内置练习模板，以半透明「幽灵参考线」引导手动裁剪，并用 IoU 重合度算法自动评分，帮助提升剪纸熟练度。 |

## 相较原爆红 App 的创新设计点

1. **多种折叠方式 + 对称可视化**：原版多为单一对折；本作内置 5 种折法，几何精确还原旋转+镜像对称群，可自由切换镜像开关。
2. **实时展开预览**：原版需点「展开」才看得到结果；本作落笔同时右侧即实时渲染整幅团花。
3. **展开动画**：扇面展开动画，从折叠态逐瓣旋转铺开，直观呈现剪纸过程。
4. **作品集与持久化**：作品本地持久化，可回看缩略图、切换线稿/辅助线视图。
5. **练习模式（原版没有）**：幽灵参考线 + IoU 自动评分，系统性提升剪纸熟练度。
6. **双裁剪笔法**：描边（线条纹样）与填充（块面镂空），更贴近真实窗花的线与面。
7. **移动端优先的触控体验**：Pointer 事件统一手指/鼠标，DPR 高清渲染，禁用页面滚动干扰。
8. **导出与分享**：一键导出 PNG。

## 本地运行

```bash
# 方式一：直接双击
open index.html        # macOS
# 或浏览器打开 index.html

# 方式二：起一个本地静态服务（推荐，避免个别浏览器对本地文件限制）
cd 剪纸可视化裁剪
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `jianzhi-sim`），将本目录文件（至少 `index.html`）推送。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 `Deploy from a branch`。
3. Branch 选 `main` / `root`，保存。
4. 等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/` 即可。

> 本应用是纯静态单文件，无需任何构建步骤，也没有后端依赖。

## 技术要点

- 折叠对称：以圆心为基准，对折叠域笔画做 `n` 次旋转；开启镜像时先在扇区自身平分线做镜像、再随扇区旋转，使相邻扇区在折痕处互为镜像，得到标准 Dₙ 对称。
- 镂空渲染：用 Canvas `globalCompositeOperation = 'destination-out'` 将裁剪路径从红纸上「挖空」，孔洞透出画布背景，呈现窗花质感。
- 实时与动画：落笔即重渲染预览；展开动画按时间轴逐扇区插值旋转角，模拟扇面铺开。
- 练习评分：将用户笔画与模板笔画分别栅格化为掩膜，计算交集/并集得到 IoU 重合度。
