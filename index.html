关于「剪纸坊」与相较原爆红 App 的创新设计点

本应用在曾经网络爆红的「中国留学生剪纸模拟」思路（折叠 → 画线 → 展开）之上，做了系统性功能补全与体验升级。核心创新如下：

1多种折叠方式 + 对称可视化：原版多为单一对折，本作内置 方形对折 / 三角三折 / 四角四折 / 六角六折 / 八角八折 五种折法，并用几何方式精确还原每种折法的旋转 + 镜像对称群，可一键切换「镜像对称」得到 Dₙ 或 Cₙ 对称。
2实时展开预览：原版需点「展开」才看得到结果；本作在折叠台上落笔的同时，右侧即实时渲染整幅展开后的团花，所见即所得。
3展开动画：提供「扇面展开」动画，从折叠态逐瓣旋转铺开，直观呈现「折 → 剪 → 展」的物理过程。
4作品集与持久化：完成的作品自动存入浏览器（localStorage），可随时回看缩略图，点击查看成品，并切换「线稿 / 辅助线」视图——线稿展示裁剪路径蓝图，辅助线展示折痕与对称轴。
5练习模式（原版没有）：内置练习模板，以半透明「幽灵参考线」引导用户手动裁剪，并用 IoU 重合度算法自动评分，帮助提升剪纸熟练度。
6双裁剪模式：支持「描边」（剪出线条纹样）与「填充」（剪出块面镂空）两种笔法，更接近真实窗花的线与面。
7移动端优先的触控体验：基于 Pointer 事件统一支持手指与鼠标，禁用页面滚动干扰，笔触按 DPR 高清渲染，手机上也能顺手剪。
8导出与分享：一键导出 PNG，方便保存或分享成品。
